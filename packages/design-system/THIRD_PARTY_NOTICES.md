# Third-party notices

Stage 04 ships local German/Latin subsets of Bricolage Grotesque, IBM Plex Sans, and
IBM Plex Mono from the Google Fonts repository at commit
`6a003b5eb672dc8bf5bff5937cf5863f8b175445`. The fonts use the SIL Open Font
License 1.1. Full notices are under `assets/licenses/`.

The closed icon geometry follows Lucide at commit
`23f9abc4ed0146cffededd3d7f94c1018bfdf693`. Lucide uses the ISC license. The
application compiles the approved paths into React exports and sets the Stage 04
contract stroke width to 1.75.

Bestehen's Threshold B symbol is repository-owned geometry copied from the Design 01
master. It is not a third-party mark.
