03 — Desktop and responsive behaviour · 1280 · 1024 · 768

Wider means more context, never more content.

The desktop layouts below add exactly one thing the phone cannot hold: the evidence behind the decision, visible at the same time as the decision. Nothing stretches, no card grows to fill a row, and the reading measure never exceeds 720px — because a B1 text set 1200px wide is a different, harder task.

Frames are drawn at their real design width. The 1280 layouts are shown at 1240 so the 12-column grid, 24px gutters and 1200 max measure are all visible at once.

D1 · ≥1280 · COACH · SIDEBAR + 7/5 SPLIT

The plan stays the subject; the reason moves beside it.

On mobile the coach's reasoning is a paragraph above the plan. On desktop it becomes a column: the same three sentences, plus the two Readiness scales they refer to, so the learner can check the claim without navigating.

D2 · ≥1280 · READINESS · 8 + 4 WITH EVIDENCE PANEL

The claim and the evidence for it, on one screen.

This is the layout that justifies a desktop build. The 8-column side holds the two gates and the section breakdown; the 4-column panel lists the attempts the estimate is made of, with their conditions and ages — the audit trail a learner needs before believing a number about their own exam.

D3 · ≥1024 · WRITING · PROMPT 4 / EDITOR 8

The task and the answer, both visible at once.

Writing is the one skill where the phone layout genuinely costs marks: scrolling away from the four obligations is how content points get missed. On desktop the prompt and the checklist stay fixed beside the editor, and the editor keeps a 720px measure so the German being written looks like the German that will be marked.

No spellcheck, no autocomplete, no grammar hints — the exam has none of these, so neither does the attempt.
The attempt shell drops the sidebar on every breakpoint: an attempt is a place, not a page inside the app. What desktop adds is only the persistent checklist — which is the difference between “write better German” and “finish the task”.
D4 · ≥1280 · MOCK · 720 MEASURE, DOCKED TIMER

Exam conditions look the same on a 27-inch monitor.

A mock is the one place where a wider window must not help. The measure stays 720, the item list stays a single column, the timer stays docked in the same position as on mobile, and everything else on the screen is removed — no sidebar, no nav, no notifications.

D5 · 768 TABLET · TOP RAIL, TWO-UP READINESS, DIALOG NOT SHEET

The breakpoint that changes the least on purpose.

480–767 gets no new layout at all — only wider padding — because inventing a fourth layout for large phones is how design systems rot. At 768 three things change: navigation moves to a top rail, the two Readiness gates sit side by side, and overlays become centred dialogs.

DESKTOP-ONLY AFFORDANCES
Keyboard answering. 1–4 or a–d select an option, Enter submits, Space plays audio, Escape leaves an overlay. Every shortcut is listed in a help panel and none is required.
Two-panel evidence. The only genuinely new layout: claim and audit trail visible together.
Print the evidence table. A learner can print the Readiness text alternative for a tutor. Charts are not printed — the table is the record.
Hover. Hover may reveal a label earlier, never information that is otherwise unavailable.
