The seven distinctions this document exists to make unmissable

Each one is a place where a plausible implementation quietly tells the learner something untrue. Each is drawn at least once, and named at the point of use.

D1 · ABSENT ESTIMATE ≠ ZERO
CORRECT
No number. Pass line still drawn.
FORBIDDEN
0
A zero is a measurement. Absence is not.
The API returns absence, not zero. Drawn at V3 (empty Progress), V6 (pending Readiness) and V8 (partial probe).

SAFEA band. Both estimates clear our margin with enough evidence.
R2BA gate over that band — six named conditions, not a higher score.

VALID PARTIALLY_VALID PENDING INTERRUPTED NOT_COUNTED

D4 · LEARNING EVIDENCE ≠ READINESS EVIDENCE
PROGRESSWhat changed in you: repairs, retention checks, milestones.
READINESSWhat would defend a booking decision: valid, current, broad enough.
A repaired weakness is not a Readiness rise, and Progress never renders a band. Stated on every Progress frame at V3.
D5 · LEARNER ERROR ≠ SYSTEM FAULT
Wrong case after mit
Red. Yours to repair.
This wasn't you.
Neutral. Ours to fix.
Identity, transfer, capability, storage, content and device faults are all the right-hand family. Never scored, never red, still visible in history.
D6 · PRESERVED WORK ≠ ACCEPTED EVIDENCE
KEPT“Your text is saved.” A durability promise about a file.
COUNTS“This moves your Reading estimate.” A claim about evidence.
One can be true while the other is false, and a failure screen must say which. Drawn at V1 and V5.
D7 · CREDENTIAL UI ≠ ACCOUNT / SESSION UI
Password, e-mail, MFA, reset: Universal Login, at its own origin. We never draw a field.
Preferences, export, deletion, sign-out, session state: ours, and only ours.
The boundary is drawn as a boundary at V1 and enforced in the account frame at V2.
READING KEY · EVERY FRAME CARRIES ITS OWN CONDITIONS AND OWNERSHIP
The mono line under each frame states the evidence label row, the validity value and the fault owner for that exact state — so no frame can be implemented without deciding them.
Compact variant strips carry loading, empty, Pending, partial, unavailable, retry, interrupted, not-counted and access states. They are deliberately not full frames.
Every family cites its Phase 1 gap (P0-1 … P1-5) and the components it reuses. A family that needed a new component would be a scope error.

Never, at any width. A password, e-mail, code or “forgot?” field on a Bestehen page. An embedded provider iframe. A provider name in a sentence. A technical code presented as a diagnosis.
Always. One primary action. A held destination that survives the round trip. Theme preference applied, because a signed-out page in the wrong theme reads as a different product.
Focus entry and return. Focus lands on the notice h1 — the first new element, never the document top. It is a page, not a dialog: no trap, no Esc, no inert background. On return, focus lands on the first element of the region left behind: the conditions row, or the destination title.
